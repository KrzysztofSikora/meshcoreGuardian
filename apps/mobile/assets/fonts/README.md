# Bundled fonts

IBM Plex Sans (400, 500, 600, 700) and IBM Plex Mono (400, 500), SIL Open Font License 1.1
(`OFL.txt`). The TTF files come from the `@expo-google-fonts/ibm-plex-sans` and
`@expo-google-fonts/ibm-plex-mono` 0.4.1 npm tarballs (`npm pack`, unpacked in a temp directory;
only the TTFs are copied). They are embedded by the `expo-font` config plugin in `app.json`, so
there is no font download at run time.
